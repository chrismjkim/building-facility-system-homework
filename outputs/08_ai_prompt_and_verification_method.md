# 생성형 AI 활용 및 검토 방식

## 사용 목적

생성형 AI는 과제의 필수 답안을 대신 작성하기 위해 사용한 것이 아니라, 냉동 사이클과 히트펌프 관련 추가학습 내용을 정리하고 검토하는 보조 도구로 사용하였다. 특히 엔탈피 중심의 냉매 사이클 해석, 압축기 흡입·토출 밸브, 몰리에르 선도 해석, 히트펌프와 ZEB·스마트그리드의 관련성을 학습노트 형식으로 정리하는 데 활용하였다.

## 사용 프롬프트 요약

이번 작업에서 사용한 원문 multi-agent prompt는 프로젝트 루트의 `TASK.md` 전체이다. 별도로 개작하지 않고 그 파일에 적힌 Agent 1~8 지시, 품질 규칙, 중지 조건을 실행 기준으로 삼았다. 사용자가 직접 준 실행 지시는 다음과 같다.

```text
Read `AGENTS.md` and `TASK.md`.
Execute the full multi-agent workflow described in `TASK.md`.
Use subagents as specified, write all deliverables to `/outputs`, and stop if any stop condition is met.
```

제출본에 프롬프트 전문을 모두 넣어야 한다면 `TASK.md`의 전체 내용을 그대로 부록에 붙이면 된다. 아래는 실제 사용한 multi-agent prompt의 핵심 구조를 요약한 것이다.

```text
건축설비시스템 Homework #02를 위한 한국어 자기주도학습 패키지를 만든다.
과제 필수 답안은 강의 수준으로 유지하고, 추가학습은 별도 삽입 섹션으로 작성한다.

Agent 1은 과제 PDF와 강의자료를 읽어 과제 범위, 필수 문항, AI 사용 기록 요구사항,
추가학습 삽입 위치를 정리한다.

Agent 2는 증기압축식 냉동 사이클을 상태점 1~4와 엔탈피 변화로 설명한다.
필수 식은 w_comp = h2 - h1, q_H = h2 - h3, h3 ≈ h4,
q_L = h1 - h4, COP_R = (h1 - h4)/(h2 - h1),
COP_HP = (h2 - h3)/(h2 - h1)이다.
냉매의 증발·응축은 화학반응이 아니라 물리적 상변화로 설명한다.
냉매 종류, 압력, 온도, 상태점이 확인되지 않으면 수치 엔탈피값을 쓰지 않는다.

Agent 3은 압축기의 suction valve와 discharge valve 역할,
압력차에 따른 개폐, 역류 방지, 내부 밸브와 서비스 밸브의 차이를 설명한다.

Agent 4는 P-h 또는 몰리에르 선도에서 포화액선, 포화증기선,
습증기 영역, 건도 x, 등압과정과 등온과정의 의미를 설명한다.

Agent 5는 히트펌프가 ZEB, 넷제로 건축, 친환경건축과 어떻게 연결되는지
IEA, IPCC, ASHRAE, NIST, DOE 등 신뢰 가능한 문헌 중심으로 검토한다.

Agent 6은 히트펌프와 스마트그리드의 연결을 수요반응, 부하이동,
축열, 피크 저감, 재생전력 연계, 제어 위험 관점에서 검토한다.

Agent 7은 모든 산출물의 식, 용어, 출처, 불확실 주장, 화학반응 오해,
수치 엔탈피 조작 여부를 A~E 등급으로 fact-check한다.

Agent 8은 앞 산출물을 바탕으로 최종 제출에 붙일 추가학습 정리,
AI 활용 및 검토 방식, 참고문헌 목록, 최종 제출 구조 제안을 작성한다.
```

## 검토 방식

- 강의자료와 과제 범위를 먼저 확인하여 필수 답안과 추가학습을 분리하였다.
- `outputs/06_fact_check_log.md`의 A~E 분류를 기준으로 식과 주요 주장을 다시 걸렀다.
- 엔탈피 식은 표준 냉동 사이클의 에너지 수지로만 사용하고, 냉매 종류와 상태 조건이 없는 수치 엔탈피 예시는 제외하였다.
- 냉매의 증발과 응축은 화학반응이 아니라 물리적 상변화로 표현되었는지 확인하였다.
- 히트펌프의 환경성, ZEB, 스마트그리드 관련 주장은 IEA, IPCC, ASHRAE, DOE/NREL, NIST, LBNL, ORNL, 학술논문 등 확인 가능한 출처가 붙은 경우에만 반영하였다.
- 웹 출처는 2026-05-31 기준으로 제목, 발행기관, DOI 또는 URL을 확인하였다.

확인한 주요 출처는 다음과 같다.

- 강의 및 과제 자료: Homework-02.pdf, 냉동기 강의 PDF, 히트펌프 강의 PDF
- 기술 참고자료: ASHRAE Handbook Chapter 38 Compressors, Copeland Refrigeration Manual, IEA Heat Pumps, IEA Demand Response, DOE Grid-Interactive Efficient Buildings, NREL GEB Technical Report
- 연구논문 및 보고서: IPCC AR6 WGIII Chapter 9, Wu & Skye(2021), Knobloch et al.(2020), Lee et al.(2020), Fischer & Madani(2017), DOE/ORNL 및 NIST 보고서

수정하거나 제외한 주장은 다음과 같다.

- 특정 냉매가 과제에 지정된 것처럼 보일 수 있는 표현은 제외하였다.
- 냉매별 엔탈피 수치, 압력, 온도 예시는 출처와 상태점이 충분하지 않아 제외하였다.
- "히트펌프는 재생에너지를 생산한다", "무전력으로 열을 얻는다"와 같은 표현은 삭제하고, "주변 열을 전기 입력으로 이동시키는 장치"로 수정하였다.
- "히트펌프는 항상 친환경이다"라는 단정은 삭제하고, COP와 전력 탄소집약도, 냉매 관리에 따라 효과가 달라진다고 정리하였다.
- 스마트그리드 효과는 일반 성능값처럼 쓰지 않고, 수요반응·부하이동·축열·제어 조건이 맞을 때 가능한 기능으로 제한하였다.
- 등온·등압 설명은 순수 냉매의 포화 2상 영역에 대한 강의 수준 설명으로 제한하고, 실제 혼합냉매나 압력강하가 있으면 차이가 날 수 있다고 덧붙였다.

## 최종 반영 방식

최종 문서에서는 과제 필수 답안 본문을 대체하지 않고, 문제 1과 문제 2 답안 뒤에 붙일 수 있는 "추가학습" 형식으로 반영하였다. 식은 기본 개념을 설명하는 데 필요한 수준으로만 넣었고, 외부 문헌 기반 내용은 ZEB, 친환경건축, 스마트그리드 관련 섹션에 한정하였다.

실제 제출 시에는 필수 답안에서 강의 그림과 과정 설명을 먼저 작성하고, 그 뒤에 본 문서의 추가학습 문단을 필요한 만큼 줄여 붙이는 방식이 적절하다. 참고문헌은 `outputs/09_reference_list.md`의 목록에서 실제 본문에 인용한 자료만 남겨도 된다.
