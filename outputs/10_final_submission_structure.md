## 2. Problem 1 required answer

### 2.1 냉동기 그림 1-a의 구성과 냉매 흐름

- 압축기, 응축기, 팽창밸브, 증발기의 위치와 역할을 강의 수준으로 설명한다.
- 기본 순서는 `압축 -> 응축 -> 팽창 -> 증발`로 쓴다.
- 냉매의 증발과 응축은 화학반응이 아니라 물리적 상변화라고 표현한다.

### 2.2 그림 1-b 몰리에르 / P-h 선도 해석

- 상태점 1, 2, 3, 4의 위치를 표시한다.
- 각 과정이 어느 장치와 연결되는지 설명한다.
- 수치 엔탈피값은 냉매 종류, 압력, 온도, 상태 조건이 주어지지 않았으므로 넣지 않는다.

## 3. Problem 2 required answer

### 3.1 히트펌프 난방 모드

- 사방밸브 전환으로 실내 열교환기가 응축기 역할을 하고 실외 열교환기가 증발기 역할을 하는 흐름을 설명한다.
- 실내 측으로 열을 방출하여 난방한다는 점을 중심으로 쓴다.

### 3.2 히트펌프 냉방 모드

- 사방밸브 전환으로 실내 열교환기가 증발기 역할을 하고 실외 열교환기가 응축기 역할을 하는 흐름을 설명한다.
- 실내에서 열을 흡수하고 실외로 방출한다는 점을 중심으로 쓴다.

### 3.3 히트펌프가 재생에너지 자원으로 고려되는 이유

- 히트펌프는 주변 열을 전기 입력으로 이동시키는 장치라고 설명한다.
- 전기를 소비하므로 무전력 또는 무배출 장치라고 단정하지 않는다.
- 재생에너지 관련성은 주변 열 이용, 고효율 전기화, 저탄소 전력과의 결합 관점에서 제한적으로 설명한다.
