# 냉매 엔탈피로 보는 증기압축 냉동사이클

## 1. 기본 관점

증기압축 냉동사이클은 강의에서 제시한 순서인 **압축 -> 응축 -> 팽창 -> 증발** 과정으로 이해한다. P-h 선도 또는 Mollier 선도에서는 각 상태점의 엔탈피 `h`를 이용해 압축기 일, 응축기 방열량, 증발기 흡열량을 식으로 정리할 수 있다.

이 문서의 설명은 특정 냉매를 가정하지 않는다. 과제 또는 강의자료에서 냉매 종류, 압력, 온도, 상태점 엔탈피가 명시되지 않았으므로 수치 엔탈피값은 사용하지 않고, 상태점 사이의 엔탈피 차이로만 설명한다.

## 2. 상태점 1~4 정리

| 상태점 | 위치 | 상태의 의미 | P-h 선도에서의 해석 |
|---|---|---|---|
| 1 | 증발기 출구, 압축기 흡입측 | 저압 냉매 증기 | 증발기에서 열을 흡수한 뒤 압축기로 들어가는 상태 |
| 2 | 압축기 출구, 응축기 입구 | 고압·고온 냉매 증기 | 1 -> 2 단열압축 후 엔탈피가 증가한 상태 |
| 3 | 응축기 출구, 팽창밸브 입구 | 고압 냉매 액체 | 2 -> 3 응축 과정에서 열을 방출한 뒤의 상태 |
| 4 | 팽창밸브 출구, 증발기 입구 | 저압·저온 냉매 | 3 -> 4 팽창밸브 통과 후 압력이 낮아진 상태 |

## 3. 과정별 엔탈피 식

### 3.1 압축기 일

압축기는 상태점 1의 냉매를 상태점 2로 압축한다. 강의의 1 -> 2 과정은 단열압축으로 다루며, 냉매 1 kg 기준 압축기 일은 다음과 같이 쓴다.

```text
w_comp = h2 - h1
```

`h2`가 `h1`보다 크므로 압축기는 외부에서 일을 받아 냉매의 압력과 온도를 높인다.

### 3.2 응축기 방열량

응축기에서는 상태점 2의 고온·고압 냉매가 열을 방출하며 상태점 3으로 이동한다.

```text
q_H = h2 - h3
```

`q_H`는 응축기에서 외부로 방출되는 열량이다. 히트펌프 난방 운전에서는 이 응축기 방열량을 실내 난방에 활용한다.

### 3.3 팽창밸브 과정

팽창밸브에서는 상태점 3에서 상태점 4로 압력이 낮아진다. 강의의 3 -> 4 과정은 팽창밸브 압력강하 과정이며, 보통 엔탈피가 거의 일정한 교축 과정으로 정리한다.

```text
h3 ≈ h4
```

따라서 팽창밸브는 압력을 낮추지만, 이상적인 해석에서는 냉매의 엔탈피 변화가 거의 없다고 본다.

### 3.4 증발기 흡열량

증발기에서는 상태점 4의 냉매가 주변에서 열을 흡수하여 상태점 1로 이동한다. 강의의 4 -> 1 과정은 증발기 정압흡열 과정이다.

```text
q_L = h1 - h4
```

`q_L`은 증발기에서 흡수하는 열량이다. 냉방 운전에서는 이 열흡수가 실내의 열을 제거하는 효과로 나타난다.

## 4. COP 식

냉동기의 성능계수는 냉동효과를 압축기 일로 나누어 계산한다.

```text
COP_R = (h1 - h4) / (h2 - h1)
```

히트펌프의 난방 성능계수는 응축기에서 방출하는 열량을 압축기 일로 나누어 계산한다.

```text
COP_HP = (h2 - h3) / (h2 - h1)
```

두 식의 분모는 모두 압축기 일이므로 `h2 - h1`이다. 차이는 목적 열량이 냉방에서는 증발기 흡열량 `h1 - h4`, 난방에서는 응축기 방열량 `h2 - h3`이라는 점이다.

## 5. 상변화 표기에 대한 주의

다음 표기는 냉매의 **물리적 상변화**를 나타내는 표현일 뿐이며, 화학반응을 의미하지 않는다.

```text
Refrigerant(l) → Refrigerant(g)
Refrigerant(g) → Refrigerant(l)
```

`Refrigerant(l) → Refrigerant(g)`는 증발기에서 냉매가 열을 흡수하며 액체 성분이 기체 성분으로 바뀌는 물리적 증발 과정이다. `Refrigerant(g) → Refrigerant(l)`는 응축기에서 냉매가 열을 방출하며 기체 성분이 액체 성분으로 바뀌는 물리적 응축 과정이다. 냉매 물질 자체가 다른 물질로 변하는 화학반응으로 설명하면 안 된다.

## 6. 과제에 넣을 수 있는 문장

증기압축 냉동사이클은 압축기, 응축기, 팽창밸브, 증발기를 순환하는 냉매의 엔탈피 변화로 설명할 수 있다. 압축기에서는 `w_comp = h2 - h1`만큼 일이 투입되고, 응축기에서는 `q_H = h2 - h3`만큼 열이 방출된다. 팽창밸브에서는 압력이 낮아지지만 교축 과정으로 보아 `h3 ≈ h4`로 정리하며, 증발기에서는 `q_L = h1 - h4`만큼 열을 흡수한다. 따라서 냉동기의 성능계수는 `COP_R = (h1 - h4)/(h2 - h1)`, 히트펌프 난방 성능계수는 `COP_HP = (h2 - h3)/(h2 - h1)`로 나타낼 수 있다.

## 7. 주의할 점

- 냉매의 증발과 응축은 화학반응이 아니라 물리적 상변화이다.
- 과제 또는 강의자료에서 냉매 종류가 제시되지 않았다면 R-134a, R-410A 등 특정 냉매를 임의로 가정하지 않는다.
- 냉매 종류, 압력, 온도, 상태점이 없으면 실제 엔탈피 수치를 계산할 수 없다.
- `h3 ≈ h4`는 팽창밸브를 교축 과정으로 단순화한 식이므로, 실제 장치의 손실이나 세부 조건을 모두 표현하는 식은 아니다.
- COP 식은 냉매 1 kg 기준 엔탈피 차이로 정리한 형태이며, 실제 장치 성능에는 압축기 효율, 열교환기 성능, 운전 조건 등이 영향을 준다. 이 문서에서는 강의 수준의 기본 사이클 해석까지만 다룬다.

## 8. 수치 예시를 생략한 이유

수치 엔탈피 예시는 생략한다. 과제 지시와 제공된 강의 근거에서 냉매 종류, 압력, 온도, 상태점의 정확한 상태가 제시되지 않았기 때문이다. 이 조건 없이 엔탈피값을 임의로 넣으면 특정 냉매나 운전조건을 가정하게 되어 과제 범위를 벗어나며, 잘못된 수치가 될 수 있다.

## 9. 식 검토 기록

| 식 | 의미 | 검토 |
|---|---|---|
| `w_comp = h2 - h1` | 1 -> 2 압축기 일 | 압축 후 엔탈피 증가분으로 정리 |
| `q_H = h2 - h3` | 2 -> 3 응축기 방열량 | 응축기에서 냉매가 잃는 엔탈피 차이로 정리 |
| `h3 ≈ h4` | 3 -> 4 팽창밸브 과정 | 교축 과정의 등엔탈피 근사로 정리 |
| `q_L = h1 - h4` | 4 -> 1 증발기 흡열량 | 증발기에서 냉매가 얻는 엔탈피 차이로 정리 |
| `COP_R = (h1 - h4)/(h2 - h1)` | 냉동기 성능계수 | 냉동효과를 압축기 일로 나눈 식 |
| `COP_HP = (h2 - h3)/(h2 - h1)` | 히트펌프 난방 성능계수 | 난방효과를 압축기 일로 나눈 식 |
