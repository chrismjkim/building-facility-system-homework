# AGENTS.md

## Project Context

This repository is for an Architectural Building Systems assignment.

The goal is to create a Korean self-directed learning package for Homework #02, focusing on:
- vapor-compression refrigeration cycle
- Mollier / pressure-enthalpy diagram interpretation
- compressor suction and discharge valves
- heat pump heating/cooling mode
- heat pump relevance to ZEB, green buildings, and smart grids

## Working Rules

- Use Korean for all student-facing outputs.
- Do not hallucinate references, equations, numerical values, or lecture claims.
- If a claim is uncertain, mark it as `확실하지 않음` or `검증 필요`.
- Do not describe refrigerant evaporation or condensation as a chemical reaction.
- Treat refrigerant phase change as physical phase change unless a credible source explicitly states otherwise.
- If the refrigerant type is not specified in the assignment or lecture PDF, do not assume a specific refrigerant.
- Do not fabricate enthalpy values.
- Only use numerical enthalpy examples when the source, refrigerant, pressure, temperature, and state point are identified.
- Keep required assignment answers at lecture level.
- Put advanced or external material under `추가학습`.
- Every external literature-review claim must have a source.
- Every equation must be checked in the fact-check log.
